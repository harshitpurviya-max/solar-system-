# Solar System Simulation 🌌

A real-time Solar System simulation built using **C++, OpenGL, and GLFW**, exploring the intersection of programming, physics, mathematics, and computer graphics.

### 🚀 About the Project

This project brings planetary motion to life through code, using mathematical calculations and physics-inspired orbital mechanics to simulate a solar system.

### 🛠️ Tech Stack
- C++
- OpenGL
- GLEW
- GLFW
- Mathematics & Physics

### ✨ Key Concepts
- Planetary orbital motion
- Mathematical transformations
- Real-time rendering
- 3D graphics programming
- Physics-based simulation

### 🎯 Objective

To explore how a powerful language like C++ can be used to translate mathematical and physical concepts into interactive visual experiences.
